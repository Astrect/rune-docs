## Introduction

Client API development servers offer a range of cheat commands that allow developers to configure their in-game characters for plugin testing.

<Callout title="Page Information" type="info">
Compiled from the [official documentation](https://developer.runescape.com/rs/cheats.html#) to provide quick, centralized access to this information.
</Callout>

<Callout title="About Cheats" type="warning">
  These cheat commands are unavailable in the live game environment. Avoid relying on their output for plugin logic unless the plugin is specifically intended for use in the development environment.
</Callout>

Commands must be entered into the client console window, which can be opened by pressing the follow key combinations:

| Platform | Key Combination |
| :--- | :---: |
| Windows | ````ALT + ` ```` |
| Linux | ````ALT + ` ```` |
| Mac OSX | ````Option + ` ```` |

<Callout title="Cheat Abuse" type="warning">
  All cheat command usage is logged on the server. Accounts found abusing these commands for any purpose may be subject to temporary or permanent bans.
</Callout>

### tele

| Syntax | Description |
| :--- | :---: |
| !tele `<coord>` | Teleports the player charater to the given full or shordhand coordinate. |
| !tele `<named_teleport>` | Teleports the player character to the named teleport destination. |

Teleports the player character to a given coordinate or named location.

Teleport to the bank at the top of Lumbridge Castle with either:

```
!tele 2,50,50,8,19
!tele 2_50_50_8_19
```

Mapsquare shorthard coordinates are also valid.
Teleport to the centre of mapsquare `50,50` with either:

```
!tele 0,50,50
!tele 0_50_50
```

Teleport to the Grand Exchange in Varrock with a named teleport destination:

```
!tele grandexchange
```

### getcoord

| Syntax | Description |
| :--- | :---: |
| `!getcoord` | Returns the current coordinate of the player character. |

Returns the current coordinate of the player character.

Useful to quickly discover tile positions for stationary NPCs, etc.

While standing at the Lumbridge Market:

```
!getcoord
0,50,50,9,56
```

<Callout title="Information" type="info">
 If the player is standing in an instance, which is built from tiles elsewhere in the game world, this command will return:

 <ul>
 <li>The coordinate within the instance</li>
 <li>The source coordinate for the tile data used at that coordinate</li>
 </ul>
</Callout>

```
!getcoord
0,104,1,40,56
Region source: 0,1,78,48,40
```

### give

| Syntax | Description |
| :--- | :---: |
| `!give <obj>` | Adds one of the given [ObjType](https://developer.runescape.com/game/config/objtype.html) to the player character's backpack (`config.Inv.INV`). |
| `!give <obj> <inv>` | Adds one of the given [ObjType](https://developer.runescape.com/game/config/objtype.html) to the player character's named [InvType](https://developer.runescape.com/game/config/invtype.html). |
| `!give <obj> <count>` | Adds `count` of the given [ObjType](https://developer.runescape.com/game/config/objtype.html) to the player character's backpack (`config.Inv.INV`). |
| `!give <obj> <count> <inv>` | Adds `count` of the given [ObjType](https://developer.runescape.com/game/config/objtype.html) to the player character's named [InvType](https://developer.runescape.com/game/config/invtype.html). |

Adds the named item(s) to a player character's inventory.
Stops when the inventory is full.

The name of the item matches the [ObjType](https://developer.runescape.com/game/config/objtype.html) and [InvType](https://developer.runescape.com/game/config/invtype.html) config names, such as:

```
config.Obj.LOGS
config.Inv.BANK
```

```bash title="example"
!give logs
!give coins 200000000 bank
```

### pouchadd

| Syntax | Description |
| :--- | :---: |
| `!pouchadd <currency_id> <count> <ignore_overflow>` | Adds the given count of the given currency type to the player character's currency pouch. |

Adds `count` of the given `currency_id` type to the player character's currency pouch.

Valid `currency_id` values can be found in the [Currency IDs](https://developer.runescape.com/rs/cheats.html#currency-ids) list.

Valid values of `ignore_overflow` are: `0` = disabled or `1` = enabled

If the new total currency would overflow that currency's maximum limit then: If `ignore_overflow` is:

- `ignore_overflow` = `1` - The total currency is clamped to the maximmum limit
- `ignore_overflow` = `0` - No currency is added

```bash title="example"

```

Removes `count` of the given `currency_id` type from the player character's currency pouch.

Valid `currency_id` values can be found in the [Currency IDs](https://developer.runescape.com/rs/cheats.html#currency-ids) list.

If the new total currency would be less than `0` then no currency is removed.

```bash title="example"
!pouchdel 9 12345
```

### pouchdeposit

| Syntax | Description |
| :--- | :---: |
| `!pouchdeposit <currency_id> <inv>` | Transfers all of the given currency type from the given inventory to the player character's currency point. |

Transfers all of the given `currency_id` type from the given [Inventory](https://developer.runescape.com/game/config/invtype.html) `inv` to the player character's currency pouch.

Valid `currency_id` values can be found in the [Currency IDs](https://developer.runescape.com/rs/cheats.html#currency-ids) list.

```bash title="example"
!pouchdeposit 11 inv
```

### pouchwithdraw

| Syntax | Description |
| :--- | :---: |
| `!pouchwithdraw <currency_id>` | Transfers the given currency type from the player character's currency pouch to the player character's `INV` inventory. |

Transfers the given currency_id type from the player's currency pouch into the player character's backpack [Inventory](https://developer.runescape.com/game/config/invtype.html) `inv`. 

A prompt will be shown to ask how much currency should be moved.

Valid `currency_id` values can be found in the [Currency IDs](https://developer.runescape.com/rs/cheats.html#currency-ids) list.

```bash title="example"
!pouchwithdraw 11
```

### testpouchadd

| Syntax | Description |
| :--- | :---: |
| `!testpouchadd <currency_id> <count>` | Tests if the exact given count of the given currency type can fit in the player character's currency pouch, adding that amount if the test is successful. |

Performs a test to see whether `count` of `currency_id` can fit in the player character's currency pouch.
If the test is successful, `count` is added. If the test is unsuccessful, nothing is added.

Valid `currency_id` values can be found in the [Currency IDs](https://developer.runescape.com/rs/cheats.html#currency-ids) list.

```bash title="example"
!testpouchadd 44 100000
```
